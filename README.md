# 🤖 AI Assistant - Enterprise Full-Stack GenAI Platform

An end-to-end, high-performance conversational AI platform built with a **MERN stack** backend and a dedicated **Python/FastAPI** microservice for LLM orchestration. Powered by the **Groq LPU Inference Engine**, the platform delivers real-time streaming responses, multi-tier model routing, RAG-driven long-term vector memory, live web search grounding, multi-modal vision and document analysis, and complete user authentication.

---

## 🌟 Key Features

### ⚡ **Real-Time SSE Streaming Pipeline**
- **Token-by-Token Streaming**: Low-latency Server-Sent Events (SSE) streaming architecture proxied seamlessly from FastAPI through Express to React.
- **Thinking Process Extraction**: Automatically parses `<think>` reasoning tags generated by DeepSeek/Qwen models and streams the reasoning trace to an interactive UI drawer.

### 🎛️ **Tiered Model Routing & Token Quotas**
- **Dynamic Tier Routing**: Intelligently routes queries based on selected performance tier:
  - 🟢 **Lite**: High-speed, lightweight model (`llama-3.1-8b-instant`).
  - 🔵 **Standard**: Balanced reasoning model (`llama-3.3-70b-versatile`).
  - 🟣 **Pro**: Advanced code and logic reasoning model (`qwen-2.5-coder-32b`).
  - 👁️ **Vision**: Multi-modal vision analysis (`qwen/qwen3.6-27b`).
- **Usage & Budget Meter**: Enforces daily token quotas per user tier stored in MongoDB (Free Tier: 1,000 tokens/day | Pro Tier: 1,000,000 tokens/day) with automatic 24-hour window resets.

### 🧠 **RAG-Driven Long-Term Vector Memory**
- **Cross-Session Fact Recall**: Automatically detects user facts (*"my name is...", "i live in...", "i work as..."*) and indexes them using TF-IDF vectorization (`scikit-learn` + `numpy`).
- **Cosine Similarity Search**: Performs semantic context retrieval per query and injects relevant memory context into system prompts.
- **Memory Management**: View recalled memory items in real-time within the Transparency Log or clear memories via API.

### 🌐 **Live Web Search Grounding**
- **Zero-Shot Query Classifier**: Utilizes a fast LLM intent check (`needs_web_search`) to decide whether real-time data or external fact checking is required.
- **Tavily Search API Integration**: Fetches real-time web facts, extracts context snippet summaries, and displays interactive verification badges and source links in the UI.

### 📄 **Multi-Format Document & Vision Processing**
- **PDF & Word Parsing**: Drag-and-drop file attachment pipeline supporting `.pdf` (`pdfplumber`) and `.docx` (`python-docx`) text extraction.
- **Base64 Vision Processing**: Drag-and-drop image analysis (`.png`, `.jpg`, `.jpeg`, `.webp`) routed to multi-modal vision models.

### 🔍 **Response Verification & Transparency Audit**
- **Automated Verifier Layer**: Evaluates generated responses for hallucination risk, factual alignment, and structural format integrity (`verifier.py`).
- **Transparency Panel**: Slide-out live telemetry panel showcasing model routing, latency (ms), vector memory matches, web search citations, and `<think>` reasoning logs.

### ✏️ **Interactive Message Controls & Tree Branching**
- **Forked Message Editing**: Edit past messages with tree truncation (truncates down-stream conversation history to allow branch explorations).
- **Regenerate & Copy**: Instant response regeneration and raw markdown copy-to-clipboard functionality.
- **Math & Markdown Engine**: Rich rendering of tables, code syntax highlighting, and $\text{\LaTeX}$ math equations using KaTeX (`$inline$` and `$$block$$`).

### 🔐 **Full-Stack Auth & User Management**
- **Dual JWT Token Security**: Access token and refresh token authentication scheme with HTTP-only credentials.
- **Google OAuth 2.0 Integration**: One-tap sign in with Google (`@react-oauth/google` and `google-auth-library`).
- **Password Recovery**: Secure password reset flow using tokenized email dispatch via Resend API (`resend`).
- **Customizable Preferences**: User profile settings for preferred model tier, dark mode, custom system prompts, and WebGL animation toggles.

### 🎨 **Modern WebGL Glassmorphic UI**
- **Dark Mode Aesthetic**: Sleek glassmorphism theme designed with TailwindCSS v4.
- **Interactive WebGL Background**: Animated WebGL Orb canvas background powered by `ogl` GLSL shaders.
- **Responsive Drawer**: Mobile-friendly sidebar drawer for search, chat creation, and conversation management.

## 🛠️ Tech Stack

### **Frontend (`/frontend`)**
- **Core Framework**: React 19 + Vite
- **Styling**: TailwindCSS v4, Custom Glassmorphism CSS
- **Graphics & Icons**: WebGL (`ogl`), Lucide React
- **Markdown & Math**: `react-markdown`, `remark-gfm`, `remark-math`, `rehype-katex`, `katex`
- **Auth & HTTP**: `@react-oauth/google`, `axios`, `react-router-dom`

### **Backend (`/backend`)**
- **Runtime**: Node.js & Express
- **Database**: MongoDB with Mongoose ORM
- **Authentication**: JWT (`jsonwebtoken`), Bcrypt (`bcrypt`), Google Auth Library (`google-auth-library`)
- **Email Service**: Resend API (`resend`)
- **Security & File Handling**: Express Rate Limit (`express-rate-limit`), Multer (`multer`), CORS

### **ML & Orchestration Microservice (`/ml-service`)**
- **Framework**: Python 3.10+, FastAPI, Uvicorn
- **Inference Engine**: Groq SDK (LPU accelerated inference)
- **Search Engine**: Tavily Search API (`tavily-python`)
- **Vector Search & Memory**: `scikit-learn` (TF-IDF), `numpy` (Cosine Similarity)
- **Document Parsing**: `pdfplumber`, `python-docx`
- **Data Validation**: `pydantic`, `python-multipart`

## 📡 API Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/auth/signup` | Register a new user account |

| `POST` | `/api/auth/refresh` | Refresh expired access tokens using refresh token |
| `POST` | `/api/auth/forgot-password` | Request password reset token via email (Resend) |

| `GET` | `/api/auth/me` | Fetch authenticated user profile & token quota |
| `PUT` | `/api/auth/settings` | Update user settings (system prompt, default tier, theme) |

### 💬 **Chat Endpoints (`/api/chat`)**
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/chat` | Retrieve all chat sessions for active user |
| `POST` | `/api/chat` | Create a new chat session |
| `GET` | `/api/chat/:id` | Fetch full message history for a specific chat |
| `PUT` | `/api/chat/:id/title` | Update chat title |
| `DELETE` | `/api/chat/:id` | Delete a chat session and associated messages |
| `POST` | `/api/chat/stream` | Send user prompt & stream SSE LLM response |

### 🐍 **ML Microservice Endpoints (`http://localhost:8000`)**
| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Microservice health check |

## 🚀 Setup & Installation

### **Prerequisites**
- **Node.js** (v18.0.0 or higher)
- **Python** (v3.10.0 or higher)
- **MongoDB** running locally on port `27017` or a MongoDB Atlas connection string
- **Groq API Key** ([Get a free key from Groq Console](https://console.groq.com/))
- *(Optional)* **Tavily API Key** ([Get a free key from Tavily](https://tavily.com/))

---

### **1. Clone the Repository**
```bash
git clone https://github.com/your-username/ai-assistant.git
cd ai-assistant
```

---

### **2. Configure Environment**
Copy `.env.example` to `.env` in the project root:
```bash
cp .env.example .env
```
Fill in your `GROQ_API_KEY`, `JWT_SECRET`, and MongoDB connection string.

---

### **3. Install Dependencies**

#### **Backend Setup**
```bash
cd backend
npm install
cd ..
```

#### **Frontend Setup**
```bash
cd frontend
npm install
cd ..
```

#### **ML Service Setup**
```bash
cd ml-service
python -m venv venv

# On Windows (PowerShell):
venv\Scripts\activate

# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
cd ..
```

---

### **4. Running the Application**

Start each service in a separate terminal window:

#### **Terminal 1: Express Backend Server**
```bash
cd backend
node server.js
```
*Backend runs on `http://localhost:5000`*

#### **Terminal 2: FastAPI ML Microservice**
```bash
cd ml-service
# Ensure virtual environment is activated
uvicorn main:app --reload --port 8000
```
*ML Microservice runs on `http://localhost:8000`*

#### **Terminal 3: Vite React Frontend**
```bash
cd frontend
npm run dev
```
*Frontend app runs on `http://localhost:5173`*

## ⚠️ Known Limitations

- **Prompt-Based Identity**: AI persona and identity boundaries are enforced via curated system prompts rather than custom fine-tuned weights.
- **Simulated Token Billing**: Daily token budget metering (1,000 / 1,000,000 tokens/day) tracks live API token consumption to demonstrate usage tier controls, but is not attached to a live Stripe billing provider.
- **Local TF-IDF Vector Storage**: Long-term RAG memory vector embeddings are stored in a local JSON structure (`memory_store.json`) using scikit-learn cosine similarity, optimal for single-instance setups.
